# sa-alkontorin-portfolio
# Портфолио системного аналитика

   Учебный проект: **учёт и синхронизация остатков для небольшого интернет-магазина**.

   ## О проекте
   Система ведёт остатки товаров и синхронизирует их между собственным сайтом, складом и маркетплейсами (Ozon, Wildberries), чтобы не допускать овербукинга.

   ## Структура
   - `requirements/` — требования, user stories
   - `diagrams/` — BPMN, UML, ER, C4, sequence
   - `sql/` — схема БД и аналитические запросы
   - `api/` — OpenAPI-спецификация, Postman-коллекции
   - `docs/` — прочая документация
